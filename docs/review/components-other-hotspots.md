# รายงานตรวจทานเนื้อหา: อุปกรณ์ขยาย เฟิร์มแวร์ อุปกรณ์ต่อพ่วง และจุดสำคัญ (hotspot)

ขอบเขต: `src/data/components/` nic, wifi, soundcard, optical, firmware, cmos, expansion, keyboard, mouse, monitor, ports
และ `src/data/hotspots/` motherboard, core, other
เกณฑ์: ความถูกต้องทางเทคนิค ณ ฮาร์ดแวร์ปี 2025–2026, ความสอดคล้องไทย–อังกฤษ, ความเป็นธรรมชาติของภาษาไทย
หลังแก้ไขได้รัน `npx vitest run` (ผ่านทั้ง 30 รายการ, 4 ไฟล์ทดสอบ) และ `npx tsc --noEmit` ผ่านทั้งโปรเจกต์

## ควรให้อาจารย์ตรวจสอบ

ไม่มี ทุกข้อที่เคยเสนอไว้ได้แก้ตามข้อเสนอแล้ว (ดูตารางด้านบน) ไม่มีประเด็นที่ต้องอาศัยดุลยพินิจของอาจารย์

## ผ่านการตรวจ

- **nic.ts**: ถูกต้อง (MAC 48 บิต/OUI, 802.3bz, Cat5e/Cat6/Cat6a กับระยะ, เลน PCIe 3.0 ไม่พอสำหรับ 10 GbE, ข้อมูลประวัติ ~3 Mbit/s) ไม่ต้องแก้
- **wifi.ts**: ถูกต้อง (QAM แต่ละรุ่น, อัตรา 2×2 ที่ 867 Mbit/s, 2.4 Gbit/s, 5.8 Gbit/s, Key E, CNVi, บลูทูธผ่าน USB, ชื่อ Wi-Fi 4/5/6 ปี 2018) แก้ 1 จุด (Bluetooth 5.x–6.0)
- **soundcard.ts**: ถูกต้อง (ไนควิสต์, 6 dB/บิต, HD Audio กับ AC'97, รหัสสีช่องเสียง, ที่มาของ 44.1 kHz) แก้ 2 จุด (overview, ระดับ line)
- **optical.ts**: ถูกต้อง (780/650/405 nm, track pitch, ความจุ, อัตรา 1× ของแต่ละรูปแบบ, EFM/EFMPlus, CLV, Class 1) ไม่ต้องแก้
- **firmware.ts**: แก้ 3 จุด (คำพิมพ์ผิด ข้อกำหนด Windows 11 และ PSP/CSME) ส่วนอื่นถูกต้อง (POST, GPT/MBR 2.2 TB, NVRAM, CSM, ไมโครโค้ด)
- **cmos.ts**: แก้ 2 จุด (รหัส IEC และเวลาถอดถ่าน) ส่วนอื่นถูกต้อง (CR2032 20×3.2 มม., 3 V, 210–240 mAh, 32.768 kHz = 2¹⁵, คำเตือนการกลืนถ่าน)
- **expansion.ts**: ถูกต้อง (2.5–32 GT/s, 8b/10b กับ 128b/130b, ปริมาณงานต่อเลน, 75 W, x1/x16 ยาว 25/89 มม.) แก้แล้วเรื่อง PCIe 6.0, ปีที่เปิดตัว, 12V-2x6 และขอบ PCIe
- **keyboard.ts**: ถูกต้อง (เมทริกซ์, debounce, ไดโอดกับ NKRO, 6KRO ของ boot protocol, อัตราโพลลิง, เกษมณี/ปัตตะโชติ) ไม่ต้องแก้
- **mouse.ts**: ถูกต้อง (cross-correlation, CPI, อัตราโพลลิง, เมาส์ของ Engelbart ปี 1968, PS/2 สีเขียว) ไม่ต้องแก้
- **monitor.ts**: ถูกต้อง (ชนิดแผง, แบนด์วิดท์ของ 4K144 ต้องใช้ HDMI 2.1 หรือ DP 1.4 + DSC, Adaptive Sync, 8.3 ล้านพิกเซล) แก้แล้วเรื่องคำเตือนแรงดันสูงและ iGPU
- **ports.ts**: แก้ 3 จุด (สาย Cat6a, การสะกด, สีพอร์ต/ชื่อ USB-IF) ส่วนชื่อ USB 3.2 Gen 1/2/2x2, USB4 40–80 Gb/s, HDMI 2.0/2.1, DP 1.4/2.1 และ PC 99 ถูกต้อง
- **hotspots/motherboard.ts**: ทุก hotspot บรรยายตำแหน่งในโมเดลได้ตรง (EPS มุมบนซ้าย, ขั้วเสียงมุมล่างซ้าย, VRM ด้านซ้ายและบนซ็อกเก็ต, ถ่านใต้สล็อต x16) ลิงก์บทเรียนเหมาะสม แก้แล้ว 3 จุด (mb-uefi, mb-cmos, mb-ram-slots)
- **hotspots/core.ts**: ถูกต้อง (LGA1700 มี 1,700 จุด, DDR4/DDR5 288 ขา, รอยบากต่างรุ่น, 6/8 พิน 75/150 W, 12VHPWR 600 W, M-key กับ B+M) ลิงก์บทเรียนเหมาะสม แก้แล้วเรื่อง 12V-2x6, ขอบ PCIe และฮีเลียม
- **hotspots/other.ts**: ถูกต้อง (IEC C14 ขากลางเป็นสายดิน, ทิศลมพัดลมออกด้านโครงยึดมอเตอร์, แรงดันบวกในเคส, รหัสสีช่องเสียง) ลิงก์บทเรียนเหมาะสม แก้แล้ว 3 จุด (kb-switch, psu-cables, port-usb)
