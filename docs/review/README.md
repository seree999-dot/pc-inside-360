## การตัดสินใจที่ใช้ในรอบสอง

1. **ข้อมูลฮาร์ดแวร์รุ่นใหม่:** เพิ่ม CPU แบบไฮบริด P-core/E-core (Intel รุ่นที่ 12 ขึ้นไป), Intel Core Ultra 200S ไม่มี Hyper-Threading (AMD ยังมี SMT), PCIe 6.0 (สเปกปี 2022 ยังไม่มีในเมนบอร์ดเดสก์ท็อป ณ ปี 2025), Bluetooth 5.4–6.0 และเรียกหัวต่อ 16 พินว่า **"12VHPWR / 12V-2x6 (16-pin)"** ทั้งโปรเจกต์ รวมถึง Assembly Lab
2. **คำศัพท์ภาษาไทย:** ใช้ "สารนำความร้อน", "อีเทอร์เน็ต", "แจ็ก" ทุกที่ (คำว่า "ซิลิโคน" เหลือเฉพาะคำค้นของ Mentor)
3. **ลำดับประกอบเครื่อง:** คงลำดับ 10 ขั้นเพื่อการสอนไว้ (ตรงกับ Assembly Lab) แต่เพิ่มคำอธิบายวิธีที่ช่างทำจริงในบทเรียน l08 และคำใบ้ของ Assembly Lab คือ ติดตั้ง CPU แรม SSD M.2 (และมักรวมชุดระบายความร้อน) บนเมนบอร์ดที่วางบนกล่องก่อนนำเข้าเคส ใส่แผ่น I/O shield ก่อนวางบอร์ด และหลายคนติดตั้ง PSU ก่อนการ์ดจอ

**แก้เพิ่มระหว่างทดสอบใช้งาน:** ข้อ i06 (ระบุ PSU) ตัดวลี "ต้นทางของสายไฟทุกเส้น" ออกจากโจทย์ เพราะเกือบเฉลยคำตอบ

**สรุป:** เฉลยของแบบทดสอบ จุดตรวจในบทเรียน และสถานการณ์แก้ปัญหาถูกต้องทั้งหมด ไม่พบคำแนะนำที่ไม่ปลอดภัย
ประเด็นที่เคยรออาจารย์ทั้ง 51 ข้อแก้แล้ว ไม่มีข้อใดค้าง ไม่มีการเปลี่ยนเฉลยหรือ id
`npx vitest run` ผ่าน 30/30 และ `npx tsc --noEmit` ผ่านทั้งโปรเจกต์
อาจารย์ยังควรอ่านทวนเนื้อหาก่อนใช้สอนจริง เพราะการตรวจครั้งนี้ทำโดย AI
